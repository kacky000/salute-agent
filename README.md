An entry for "Your Agent in One Emoji": the saluting face, because an agent says "On it!" to every request before it knows what the request is.

## Run it

```sh
node main.ts
```

It writes the emoji to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR`).
